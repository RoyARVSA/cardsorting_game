# 每日分類挑戰 試玩版

完整的現行功能、出題演算法、資料結構、驗收條件與未來雲端排行榜方向，請閱讀 [完整專案規格書](SPECIFICATION.md)。該文件以完成作品為準，並將尚未實作的功能獨立標示。

背景回饋：每次作答立即出現較明顯紅／綠，150毫秒退至淡色，800毫秒後開始淡出，1200毫秒恢復背景；連續同色也重新觸發。卡片內容與上方文字時間不變。

只需上傳 **index.html**。HTML、CSS、JavaScript、SVG 卡片全部寫在同一個檔案，不需要圖片資料夾、安裝套件、API 金鑰或後端。

## 上傳到 GitHub Pages

1. 在 GitHub 建立你的專案（一般免費帳號可先使用公開 repository）。
2. 在專案選 **Add file → Upload files**，上傳 `index.html` 到專案根目錄，按 **Commit changes**。
3. 開啟專案 **Settings → Pages**。
4. 在 **Build and deployment** 的 **Source** 選 **Deploy from a branch**。
5. Branch 選放置檔案的分支（通常為 `main`），資料夾選 **/ (root)**，按 **Save**。
6. 等部署完成，從 Pages 顯示的 **Visit site** 開啟網站。一般網址形式是 `https://你的帳號.github.io/專案名稱/`。
7. 後續更新直接上傳並取代 `index.html`。若仍看見舊版，重新整理或清除網站快取；清除網站資料則也可能刪掉遊戲紀錄。

不需要上傳 `tests` 或 `docs` 才能執行網站。可額外上傳 README 方便日後維護；不要將整個資料夾當成壓縮檔上傳後期待 Pages 自動解壓。

GitHub 官方文件：[建立 Pages 網站](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)、[Pages 發布來源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。帳號或組織權限若不允許 Pages，需先確認專案設定。

## 玩法

- 三分鐘、每題十秒、八個規則區段，點選四張參考卡之一分類。
- 紅、藍、黃、綠；圓、三角、正方、十字；1–4 個；實線、虛線、點線、雙線。
- 三個圖案排成三角形，四個排四角。所有圖案都是內嵌 SVG。
- 答對加 100 分，答錯扣 40 分，允許負分；逾時不扣分，無連擊倍率或額外獎金。
- 依台北日期產生每日相同挑戰；同一挑戰可以重玩。
- 頁面隱藏、鎖屏或重新整理會中止，不占首次完成。瀏覽器執行停滯超過兩秒也視為技術中斷。
- 跨午夜的局繼續玩完並結算，之後只可開始新一天的挑戰。
- 本機保留七天完成紀錄、區段與逐題內容；首次完成及重玩最佳分開。
- 無登入、暱稱、排行榜、追蹤服務或資料上傳。

## 上線後請依序測試

### 桌面與手機都做一次

1. 用 Chrome 或 Safari 等一般瀏覽器開啟正式 Pages 網址，先避免通訊 App 的內嵌瀏覽器。
2. 確認四種顏色與框線能分清，三個圖案為三角形、四個為四角。
3. 按開始，確認準備時間不占三分鐘，手機卡片不需橫向捲動。
4. 點選幾題：上方出現「上一題」正確／錯誤，下一張立即出現。
5. 故意等一題十秒，確認只記一次逾時並換題。
6. 完成三分鐘，確認分數等於答對題數乘以 100 減去答錯題數乘以 40，最後未完成題不算逾時。
7. 展開區段、統計及逐題紀錄，查看八段規則、對錯、反應時間與行為分類。
8. 回到首頁並重新整理，確認首次完成成績仍存在。
9. 再完成一次，確認首次分數不被覆蓋，另有重玩最佳。

### 中斷測試

- 另開一局，切換分頁再回來：應顯示中斷，不能續玩。
- 手機另開一局，切到其他 App 或鎖屏後回來：應中斷。
- 遊戲中重新整理：不應續局，也不應產生完成分數。
- 旋轉手機：若瀏覽器未隱藏或凍結，應繼續原局，不換題庫。
- 很慢的裝置若頻繁顯示技術中斷，請記錄裝置、瀏覽器版本、出現時機，以便調整。

### 午夜與紀錄

- 台北 23:58 左右開始一局，跨 00:00 後完成：結果應歸原日期，下一局使用新日期。
- 不提供任意舊日期重玩，也沒有跨午夜重玩資格。
- 本機紀錄頁可清除資料，這會重設首次完成狀態，無法還原。
- 七天到期資料在下一次開啟、讀取或保存紀錄時清理，網頁關閉時不會在背景自動執行。

## 限制與回報

- 本機紀錄不跨裝置、瀏覽器、網站來源同步；無痕模式或清除網站資料可能使紀錄消失。
- 目前依裝置時鐘決定台北日期，不防止手動改時間、清除資料或查看程式。
- 首次完成不代表首次看過題目；中斷後重來仍可能熟悉題目。
- 儲存失敗時結果暫存在該頁記憶體，請不要關閉或重新整理。
- 自訂行為分類不是標準 WCST 計分，不提供人格或心理診斷。
- 實際鎖屏事件與效能需要在你使用的 iPhone／Android 上試玩確認。

回報問題時請提供：日期、裝置與瀏覽器、卡在哪一步、畫面文字或截圖。不要只提供高低分，因為分數本身不表示程式出錯。

## 開發驗證

網站本身不需要 Node。若要執行附帶測試，安裝 Node 後在專案資料夾執行：

```text
node --test tests/core.test.cjs tests/ui-state.test.cjs
```

核心測試包含 366 個日期、2,928 組完整卡片及部分延伸批次驗證，需數分鐘。
狀態測試使用可控時間與最小 DOM 容器驗證輸入生命週期，不替代真實手機實測。

本機 HTTP 預覽：

```text
node tests/serve.cjs
```

開啟 `http://127.0.0.1:4173`，使用 Ctrl+C 停止伺服器。此網址只在執行伺服器的電腦上可用；手機測試請使用上線後的 GitHub Pages 網址。
